Thousands of monarch butterflies pour out of a mountain peak like lava, a glowing orange eruption against a deep blue night sky. The program ships that single image and copies it, byte for byte, to the entry output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
